# Nyalthe

Public proof for private claims on Starknet.

Nyalthe is a privacy-preserving parametric claims rail built for the STRK20 Private Sprint. It is designed to let a funded event policy settle a protected claimant payout while the public can verify the policy, event, contract, and settlement.

## Status

Early public build. The repository will track the implementation, tests, Starknet deployment, and verified STRK20 transactions as they become available.

## Planned Flow

`Create policy -> Fund reserve -> Accept signed event -> Authorize claim -> Settle privately -> Inspect receipts`
